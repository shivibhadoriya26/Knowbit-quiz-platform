# Knowbit – Technical Quiz Application

A quiz application developed using Python and Streamlit.

## Features

- User registration and login
- Six quiz categories:
  - Data Structures and Algorithms (DSA)
  - Database Management Systems (DBMS)
  - Python
  - System Design
  - Java
  - C++
- 20 multiple-choice questions per subject
- Automatic score calculation
- Quiz result display
- Answer review
- Retry quiz option
- User progress tracking
- Recent quiz attempts
- Logout functionality

## Technologies Used

- Python
- Streamlit
- HTML
- CSS

## Installation and Execution

**1. Clone the repository**

```bash
git clone https://github.com/shivibhadoriya26/Knowbit-quiz-platform.git
```

**2. Navigate to the project directory**

```bash
cd Knowbit-quiz-platform
```

**3. Install the required packages**

```bash
pip install -r requirements.txt
```

**4. Run the application**

```bash
python -m streamlit run app.py
```
